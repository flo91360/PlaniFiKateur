Connecter votre agent

La description et les critères d’acceptation de la carte constituent la demande transmise à l’agent. Le parcours dans le site est prêt. Pour qu’une carte soit réellement traitée, connectez un agent qui tourne dans votre propre service.

  1. Depuis une carte, un administrateur crée la clé dans « Connexion de l’agent ».
  2. Placez la clé dans les secrets du service agent. Utilisez HTTPS et l’en-tête Authorization: Bearer <clé-agent>.
  3. L’agent consulte GET /api/v1/projects/{projet}/work et réserve une exécution avec POST /api/v1/projects/{projet}/cards/{carte}/work/{execution}/claim et sa version.
  4. Il confirme sa présence toutes les 60 secondes avec heartbeat, puis utilise question, progress ou submit. La réservation expire après cinq minutes sans réponse.
  5. Vous répondez aux questions depuis la carte. Les livraisons GitHub sont terminées après tests et fusion automatiques ; les résultats sans PR restent à valider. L’agent reprend une tâche corrigée en la réservant à nouveau.

Le client de référence scripts/agent-client.mjs dans le dépôt facilite les appels. Aucun modèle ou outil externe n’est lancé automatiquement par le site.
